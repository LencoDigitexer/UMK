# Шаблон конспекта урока (для тиражирования)

> Заполняется для каждой темы КТП. Обязательная структура сохранена — не удалять разделы.
> Временные нормы: 90 мин (1 ч теория + 1 ч практика), перемена 5–10 мин внутри Этапа 2.

---

## 1. ПАСПОРТ УРОКА
- **Предмет и класс:** Программирование роботов, ___ класс (доп. образование)
- **Тема по КТП:** Кейс ___, Тема ___. «____________»
- **Номер урока в теме / общий номер:** ___ (дата по КТП: __.__)
- **Тип урока:** изучение нового / закрепление / комбинированный / проектный / контроль
- **Цель урока (глобальная):** …
- **Задачи (через деятельность ученика):**
  - *Образовательная:* ученик (делает что?) …
  - *Развивающая:* ученик тренирует/развивает …
  - *Воспитательная:* ученик проявляет …
  - *Метапредметная:* ученик устанавливает связи / моделирует …
- **Оборудование:** роботы VEX IQ / ноутбуки с VEXcode IQ / датчики ___ / трасса / карточки…
- **Связь с кодификатором:** умения № ___ (см. `01_Кодификатор_умений.md`)
- **Специфика группы:** «Исследователь» — роль ___, «Творец» — роль ___, «Практик» — роль ___ (см. `03_Карточки_типов_детей.md`)

## 2. ГЛАВНАЯ ЛИНИЯ УРОКА (2–3 предложения)
РАСКРЫВАЕМ: … РАЗВИВАЕМ: … ПРОДВИГАЕМ: …

## 3. ХОД УРОКА

### ЭТАП 1. Постановка задачи и мотивация (Вектор: РАСКРЫВАЕМ) — ___ мин
- **Цель этапа:** зацепить внимание, актуализировать личный опыт, создать интригу/противоречие.
- **Действия педагога:** приём(ы) № ___ из банка; как создаём безопасную среду гипотез; как дети сами формулируют цель.
- **Действия учеников:** ассоциации, версии, вопросы, личная цель на урок.
- **Методический комментарий:** как раскрывается индивидуальность каждого типа детей.

### ЭТАП 2. Содержание и основная деятельность (Вектор: РАЗВИВАЕМ) — ___ мин
- **Цель этапа:** добыча знаний, отработка навыков, развитие мышления.
- **Блок 2.1 (теория, ~__ мин):** …
- **Перемена (~__ мин):** …
- **Блок 2.2 (практика, ~__ мин):** работа в парах/группах, роли, задание(я), уровни поддержки (приём №37).
- **Действия педагога:** фасилитация вопросами, поддержка в ЗБР, никаких готовых ответов.
- **Действия учеников:** исследование, дискуссия, сборка/код, создание продукта.
- **Методический комментарий:** какие hard/soft навыки развиваем.

### ЭТАП 3. Подведение итогов и закрепление (Вектор: ПРОДВИГАЕМ) — ___ мин
- **Цель этапа:** синтез опыта, фиксация прогресса, выход в применение.
- **Действия педагога:** мини-выставка/защита продуктов, структурирование знания (схема «жизнь→схема→код→робот»), отметка в чек-листе кодификатора.
- **Действия учеников:** защита за 30 секунд (приём №21), самооценка вклада, вывод «что я теперь умею».
- **Методический комментарий:** конкретный «шажок вперёд» для каждого типа ребёнка.

### ЭТАП 4. Рефлексия (Вектор: ЛИЧНЫЙ РОСТ И ОСМЫСЛЕНИЕ) — ___ мин
- **Цель этапа:** осмысление пути: не только «что узнал», но «каким стал».
- **Действия педагога:** пространство честной обратной связи без оценок.
- **Приёмы рефлексии (выбрать 1–2 нестандартных):** … (идеи: «Дебаггинг дня», «Псевдокод моего состояния», «Письмо себе» №30, «Лестница успеха» №29)
- **Методический комментарий:** фокус на ответственности за собственный рост.

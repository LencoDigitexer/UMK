# Конспекты уроков «Программирование роботов»

Библиотека планов занятий (конспектов) по программе дополнительного образования
**«Программирование роботов на VEX IQ»** (КТП — `КТП ПР1 Робототехника.doc`). 

## 🌟 Главная линия: ДЕТЕЙ РАСКРЫВАЕМ, РАЗВИВАЕМ, ПРОДВИГАЕМ

Каждый конспект построен на триаде:

| Вектор | Что это значит на уроке |
|---|---|
| **РАСКРЫВАЕМ** | Среда, где каждый ребёнок проявляет скрытые таланты, актуализирует личный опыт, высказывает уникальное мнение и чувствует свою значимость (Этап 1 — мотивация и постановка задачи). |
| **РАЗВИВАЕМ** | Деятельность, тренирующая soft & hard skills, критическое и алгоритмическое мышление, креативность, командную работу (Этап 2 — содержание и основная деятельность). |
| **ПРОДВИГАЕМ** | Реальный образовательный прогресс: переход из зоны актуального развития в зону ближайшего, фиксация нового знания и инструмента (Этап 3 — итоги и закрепление). Плюс Этап 4 — рефлексия личного роста. |

## 📁 Структура папок

```
├── _методические_материалы/          ← навигатор по КТП, кодификатор, приёмы, чек-листы
│   ├── 00_Навигатор_по_КТП.md        (все кейсы и темы с датами и часами)
│   ├── 01_Кодификатор_умений.md      (перечень проверяемых требований → темы уроков)
│   ├── 02_Банк_педагогических_приёмов.md (40 приёмов + адаптация под робототехнику)
│   └── 03_Карточки_типов_детей.md    («Исследователь», «Творец», «Практик»)
├── Кейс_1_Scratch/                   ← Основы программирования в Scratch 3 (уроки 1–16)
├── Кейс_2_VEX_IQ_движение/           ← Движение роботов VEX IQ в VEXcode IQ (уроки 17–33)
├── Кейс_3_Внешнее_управление/        ← Внешнее управление роботом (уроки 34–45)
├── Кейс_4_Манипуляторы/              ← Роботы-манипуляторы, пневматика (уроки 46–57)
└── Кейс_5_Производственные_линии/    ← Программирование производственных линий (уроки 58–70)
```

Каждая тема содержит файл `УрокNN_….md` — полный конспект по обязательной структуре:
**Паспорт урока → Главная линия → Ход урока (4 этапа с методическими комментариями)**.

## 🔧 Инструментальная база (спецификаторы)

- **VEX IQ / VEXcode IQ** — видеоматериалы и методика: <http://vexacademy.ru/vex-iq-video.html>
- **Arduino / КПМИ-Про** (модули внешнего управления и датчиков) — <https://wiki.appliedrobotics.ru/metod/KPMIS_Pro/index.html>
- Кодификатор — «Перечень проверяемых требований к результатам освоения программы „Программирование роботов“».

## 👥 Специфика группы

В каждой группе работают дети трёх типов, и каждый этап урока даёт им «свою роль»:

- **«Исследователь»** — гипотезы, эксперименты с датчиками, поиск закономерностей;
- **«Творец»** — дизайн маршрута/проекта, нестандартные решения, презентация;
- **«Практик»** — сборка, калибровка, доведение механики и кода до надёжной работы.

Подробно — в `_методические_материалы/03_Карточки_типов_детей.md`.

## ✍️ Как пользоваться

1. Откройте нужный кейс и тему по дате из «Навигатора по КТП».
2. Прочитайте «Главную линию урока» — это концепция в 3 предложениях.
3. Ведите урок по 4 этапам; приёмы рефлексии чередуйте по банку приёмов.
4. После урока отметьте освоенные умения в чек-листе кодификатора — так виден прогресс каждого ребёнка.
